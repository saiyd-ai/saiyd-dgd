A  CLASSIFICATION — which option to use?

1. UN1266 PERFUMERY PRODUCTS, Class 3 (standard DG shipment, IMP code RFL):
• PG II (flash point < 23°C): PAX — PI 353, max 5 L/pkg • CAO — PI 364, max 60 L
• PG III (flash point 23–60°C): PAX — PI 355, max 60 L/pkg • CAO — PI 366, max 220 L
• UN specification packaging + Class 3 label + orientation arrows required. Most perfumes (70-90% ethanol) have FP 12–23°C → usually PG II or PG III.

2. LIMITED QUANTITY (cheaper, no UN spec packaging):
• PG II: Y341 — max 1 L per inner, 1 L per package • PG III: Y344 — max 10 L per package.
• DGD still required. Ltd Qty mark ("Y") on package.

3. EXCEPTED QUANTITY (samples — NO DGD needed!):
• PG II: E2 — max 30 mL per inner, 500 mL per package • PG III: E1 — max 30 mL inner, 1 L per package.
• Only the red/white EQ mark on the box; no DGD, no DG fee. Best for samples.

4. ID8000 CONSUMER COMMODITY, Class 9 (retail-packed): PI Y963, max 30 kg G/pkg. Easiest for finished retail perfume; very common for USA.

B  DESTINATION RULES (worldwide)

• USA: 24-hr emergency phone on DGD mandatory (49 CFR / USG variation). ID8000 widely accepted. DG training certificate required for signatory.
• Europe (EU/UK): IATA rules apply for air; road delivery legs follow ADR (Ltd Qty easy). Carrier variations: LH, AF, BA, KL — check each.
• UAE / GCC: GCAA/Emirates SkyCargo (EK) variations — EK accepts UN1266 PAX & CAO; pre-book DG space.
• India: DGCA — UN1266 accepted; some carriers CAO-only for PG II; MSDS copy usually requested.
• China / Japan / Korea: MSDS in English mandatory at acceptance; some airports restrict PG II on PAX.
• Australia / NZ: CASA follows IATA; standard.
• Courier (DHL/FedEx/UPS/Aramex): each has own DG approval program — perfume needs DG account/contract; ID8000 & Ltd Qty easiest.
